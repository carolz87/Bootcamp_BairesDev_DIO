# Estudo de Binarização de Imagem

Este repositório contém um estudo de binarização de imagem utilizando Python, desenvolvido como parte do desafio do Bootcamp da BairesDev pela DIO.

## Objetivo

O objetivo deste projeto é aplicar técnicas de binarização de imagem para converter imagens em escala de cinza para imagens binárias, onde os pixels são representados apenas por valores 0 e 1.

## Ferramentas Utilizadas

- Python 3.x
- Bibliotecas: OpenCV, NumPy, Matplotlib

## Estrutura do Projeto


- `imagens/`: Contém as imagens de exemplo utilizadas no estudo.
